# Math Clash — مطر المعادلات 💧

لعبة حساب ذهني عربية أولًا: **قطرات تحمل مسائل تتساقط، وأنت تكتب الناتج لتفجّرها قبل أن تصل الأرض.**
سرعة استجابة فورية، عواصف تشتد، قطرات خاصة، مباريات مباشرة ضد لاعبين حقيقيين، غرف للأصدقاء، بطولات للمواسم والمناسبات تديرها من لوحتك، ولوحات صدارة حقيقية متحقَّق منها — مع قسم تعلّم هادئ للأطفال.

- تعمل **بلا إنترنت** للعب الفردي والتعلّم (PWA)، والأونلاين عند توفر الاتصال.
- العربية والإنجليزية كاملتان، و11 لغة أخرى للعناوين الأساسية.
- جاهزة للنشر كتطبيق **Google Play** (TWA) — انظر [docs/DEPLOY_AND_GOOGLE_PLAY.md](docs/DEPLOY_AND_GOOGLE_PLAY.md).

## التشغيل

```bash
npm install
npm run dev          # اللعبة + الخادم: http://localhost:8080   ·   الإدارة: http://localhost:8080/admin
npm test             # اختبارات المنطق + الخادم
npm run test:e2e     # اختبارات المتصفح (لاعب واحد + عدة لاعبين أونلاين + لوحة الإدارة)
```
يتطلب Node.js 22.13 أو أحدث (قاعدة SQLite مدمجة في Node — بلا خدمات خارجية).

## اللعب

### المطر — اللعبة الأساسية
- القطرة تحمل مسألة (`7 + 5`، `6 × 4`، `□ − 8 = 9`…). اكتب الناتج فتنفجر **فور كتابة الرقم الصحيح**؛ إذا تشابهت بدايات نواتج قطرتين ظاهرتين انتظر حتى تكمل أو اضغط ✓.
- **الاستجابة**: أزرار لوحة الأرقام تعمل لحظة لمس الإصبع (لا عند رفعه)، ويدعم لوحة المفاتيح بالأرقام العربية والإنجليزية.
- **النقاط**: 100 + 10 لكل مستوى صعوبة، × السلسلة حتى 1.5، + حتى 50 كلما فجّرت القطرة أعلى. الخطأ لا يخصم نقاطًا.
- **قطرات خاصة**: ⭐ ضعف النقاط · ❄️ تبطئ المطر 5 ثوانٍ · ⚡ تفجّر كل القطرات الظاهرة.
- **العدالة**: لا تسقط أي قطرة أسرع من (زمن حلّها المتوقع × 1.3)، ولا تظهر قطرتان بنفس الناتج معًا.
- **محرّك حتمي**: 60 نبضة ثابتة في الثانية + بذرة عشوائية + سجل الإدخال ⇐ يعيد الخادم تشغيل أي جولة حرفيًا للتحقق منها، ويستأنف الجهاز الجولة بعد تحديث الصفحة بدقة.

| النمط | الفكرة |
|---|---|
| **رحلة المستويات** | 100 مرحلة في 10 عوالم (المطر الخفيف ← الأسطورة). مرحلة عادية: فجّر الهدف دون فقد 3 قلوب (النجوم = القلوب المتبقية). ⚡ سرعة: الهدف قبل نفاد الوقت. 👑 زعيم: هدف أكبر وقطرات خاصة. |
| **عاصفة الوقت** | 30/60/120 ثانية، المطر يشتد تدريجيًا. الرقم القياسي = عدد القطرات. |
| **البقاء** | 3 قلوب ومطر لا ينتهي يزداد سرعة وصعوبة. |
| **التحدي اليومي** | عاصفة 90 ثانية **بنفس القطرات للجميع** في اليوم، محاولة رسمية واحدة (تُرفع للوحة «اليوم» عند الاتصال)، والإعادات تدريب فقط. بلا إيقاف. |
| **التدريب الحر والدروس** (للأطفال والتعلّم) | أسئلة هادئة بلا مطر: اختيار، إدخال، عدد مفقود، مقارنة، كسور، نسب، أسس، أقواس — مع شرح بعد كل خطأ، و56 درسًا متدرّجًا من 4 سنوات فما فوق. |
| **تحدي صديق (نفس الجهاز)** | بالتناوب أو شاشة مقسومة وجهًا لوجه، بأسئلة متكافئة. |

### الأونلاين
| الميزة | التفاصيل |
|---|---|
| **مباراة سريعة** | خصم حقيقي بأقرب تصنيف، نفس القطرات لكما، وترى نتيجته مباشرة أثناء اللعب. إن لم يوجد لاعب خلال ثوانٍ تلعب ضد **«شبح»**: جولة مسجّلة حقيقية للاعب آخر (موضّحة بوضوح 👻 — لا لاعبين وهميين). تصنيف Elo لكل موسم. |
| **غرف الأصدقاء** | رمز من 6 أرقام، حتى 8 لاعبين، المضيف يختار الصعوبة والمدة والنمط (سباق/فريقان) والقطرات الخاصة. |
| **البطولات** | تنشئها من لوحة الإدارة لأي مناسبة أو موسم بموعد بداية ونهاية؛ تظهر تلقائيًا للاعبين، وتُمنح الجوائز تلقائيًا لأفضل N عند الانتهاء. |
| **العاصفة الأسبوعية** | دقيقة واحدة؛ لوحة صدارة تبدأ من جديد كل أسبوع. |
| **لوحات الصدارة** | الأسبوع، الموسم، اليوم، الأصدقاء، الكل — كلها من نتائج تحقّق منها الخادم. |
| **الأصدقاء والتحدي بالرابط** | أضف صديقًا برمزه؛ وبعد أي جولة «تحدَّ صديقًا بهذه العاصفة» يصنع رابطًا يلعب فيه صديقك نفس القطرات تمامًا. |
| **التفاعل الآمن للأطفال** | رموز تعبيرية جاهزة فقط (👏🔥😮😂💪🎉👋❤️) — بلا دردشة نصية. الأسماء مُفلترة ويمكن للمسؤول إيقافها. |
| **حذف الحساب** | من صفحة الأونلاين (متطلب Google Play). |

### مكافحة الغش
- الجهاز لا يرسل النتيجة بل **سجل الإدخال**؛ الخادم يعيد تشغيله على المحرّك نفسه ويحسب النتيجة.
- تُرفض الجولة إذا انتهت أسرع من زمنها الحقيقي، أو تأخرت بشكل غير منطقي (تشغيل بطيء)، أو كانت سرعة الإجابة غير بشرية (أكثر من 30% من الإجابات أسرع من 250ms).
- حدود للطلبات لكل عنوان، وحد للرسائل في WebSocket.

## لوحة الإدارة (`/admin`)
البطولات حسب المناسبة (رمضان، العيد، اليوم الوطني، يوم التأسيس، الصيف، العودة للمدارس، الشتاء، العام الجديد، مخصّصة) مع جدولة واختصارات مواعيد ومعاينة، والمواسم، والإعلانات، وإدارة اللاعبين. التفاصيل في [docs/DEPLOY_AND_GOOGLE_PLAY.md](docs/DEPLOY_AND_GOOGLE_PLAY.md).

## التقدّم والحفظ
- الخبرة والمستويات، 18 شارة، 3 مهام يومية، مظاهر تجميلية للقطرة (ألوان وزينة وسمات) لا تؤثر على اللعب، وجوائز البطولات.
- صفحة «تقدّمي»: الجولات، الأسئلة، الدقة، متوسط زمن الإجابة (من ظهور القطرة حتى تفجيرها)، أفضل نتيجة لكل نمط، مستوى كل عملية (تكيّفي 1–10)، رسم آخر 14 يومًا، وتوصية تدريبية — مع تعريف كل مؤشر داخل الصفحة.
- **التقدّم الفردي محلي** (localStorage) لكل ملف شخصي على الجهاز، مع تصدير/استيراد. **الأونلاين** محفوظ على الخادم (الاسم، النتائج، الأصدقاء، التصنيف، الجوائز). لا توجد مزامنة للتقدّم الفردي بين الأجهزة.
- تُرحَّل بيانات النسخة الأولى (أحادية الملف) تلقائيًا دون حذفها.

## البنية
```
public/                  ← ملفات اللعبة (تُخدم من الخادم أو أي استضافة ثابتة)
  src/core/              منطق خالص مشترك بين الجهاز والخادم:
    rain.js              محرّك المطر الحتمي + إعادة التشغيل + فحص المعقولية
    questions.js         مولّد الأسئلة وسياسة الأعداد
    modes.js             الأنماط والمراحل
    session.js           محرّك جولات الأسئلة (التدريب والدروس)
    progression.js       الإحصاءات، الخبرة، الشارات، المهام، المكافآت (مرة واحدة)
    storage.js           الملفات الشخصية والحفظ والترحيل
  src/net/online.js      الاتصال بالخادم (REST + WebSocket بإعادة اتصال)
  src/screens/           الشاشات (rain.js = شاشة اللعب الأساسية، online.js = الأونلاين)
  src/admin/admin.js     لوحة الإدارة (admin.html)
  privacy.html           سياسة الخصوصية
server/
  index.js               HTTP: الملفات + REST + الإدارة + حدود الطلبات
  realtime.js            WebSocket: البحث عن خصم، الغرف، التقدّم المباشر، التفاعلات
  services.js            اللاعبون، التحقق، الصدارة، البطولات، المواسم، الأصدقاء، التحديات
  db.js                  مخطط SQLite
deploy/                  Docker Compose + Caddy (HTTPS تلقائي)
tests/unit|server|e2e/   الاختبارات
```

## سياسة الأسئلة (مختصر)
كل الإجابات أعداد صحيحة (لا تقريب)؛ القسمة بلا باقٍ ولا قسمة على صفر أو واحد؛ السوالب من المستوى 8 في الطرح و9 في الجمع فقط؛ المعادلات معزولة الاتجاه (LTR) فلا تنعكس `5 − 3` في الواجهة العربية؛ الصعوبة التكيّفية تتغيّر بخطوات صغيرة بعد 6 إجابات جديدة على الأقل.
