# Math Clash — حزمة النشر على Cloudflare Pages

لعبة **مطر المعادلات**: قطرات تحمل معادلات تتساقط، واللاعب يكتب الناتج فتنفجر القطرة المطابقة.

---

## محتويات الحزمة

| الملف | الوظيفة |
|---|---|
| `index.html` | اللعبة كاملة — ملف واحد مكتفٍ بذاته (لا يحتاج بناء ولا حزم) |
| `manifest.webmanifest` | يجعل اللعبة **قابلة للتثبيت** على الجوال كتطبيق |
| `sw.js` | عامل خدمة — تعمل اللعبة **بلا إنترنت** بعد أول زيارة |
| `_headers` | رؤوس الأمان والتخزين المؤقت (خاص بـ Cloudflare Pages) |
| `404.html` | صفحة خطأ مخصّصة |
| `icon-*.png` | أيقونات التطبيق |
| `robots.txt` | سماح لمحركات البحث |

> **لا يوجد أمر بناء (build).** الموقع ثابت بالكامل — ارفعه كما هو.

---

## الطريقة ١: السحب والإفلات (الأسرع — دقيقتان)

1. ادخل [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → تبويب **Pages** → **Upload assets**.
2. اكتب اسم المشروع، مثلاً `math-clash`.
3. اسحب **محتويات المجلد** (لا المجلد نفسه) إلى منطقة الرفع — أي: `index.html`, `sw.js`, `manifest.webmanifest`, `_headers`, `404.html`, وكل ملفات `.png`.
4. اضغط **Deploy**.

سيصبح الرابط: `https://math-clash.pages.dev`

> **مهم:** تأكّد أن `index.html` في **جذر** الرفع مباشرة، لا داخل مجلد فرعي — وإلا ستظهر صفحة فارغة.

---

## الطريقة ٢: سطر الأوامر (Wrangler)

```bash
# مرة واحدة
npm install -g wrangler
wrangler login

# من داخل مجلد الحزمة
wrangler pages deploy . --project-name=math-clash
```

للتحديث لاحقاً: عدّل `index.html` وأعد تنفيذ أمر `deploy` نفسه.

---

## الطريقة ٣: الربط بـ GitHub (نشر تلقائي)

1. ارفع محتويات المجلد إلى مستودع GitHub.
2. في Cloudflare: **Workers & Pages** → **Create** → **Pages** → **Connect to Git** → اختر المستودع.
3. في إعدادات البناء:
   - **Framework preset:** `None`
   - **Build command:** *(اتركه فارغاً)*
   - **Build output directory:** `/`
4. **Save and Deploy**.

بعدها أي `git push` ينشر تلقائياً.

## بعد النشر

- **نطاق مخصّص:** من صفحة المشروع → **Custom domains** → **Set up a domain**.
- **التثبيت على الجوال:** افتح الرابط في المتصفح → قائمة المشاركة → «إضافة إلى الشاشة الرئيسية». ستعمل اللعبة كتطبيق مستقل وبلا إنترنت.
- **التحديث:** بعد رفع نسخة جديدة، **غيّر رقم الإصدار** في أول سطر من `sw.js`:
  ```js
  const CACHE = 'math-clash-v2';   // كان v1
  ```
  بدون هذا التغيير قد يظل المستخدمون على النسخة القديمة المخزّنة.

## ملاحظات تقنية

- **الحفظ المحلي:** التقدّم والنجوم والإعدادات تُحفظ في `localStorage` على جهاز اللاعب فقط. لا يوجد خادم ولا قاعدة بيانات.
- **«الأونلاين» محاكاة:** الخصوم والغرف والبطولة تعمل حالياً بمحاكاة محلية. للأونلاين الحقيقي بين أجهزة مختلفة يلزم خادم — ويمكن بناؤه على **Cloudflare Workers + Durable Objects** (مناسب جداً لغرف اللعب بالرمز)، أو الانتقال إلى Unity + Photon كما خُطّط.
- **الأصوات** مولّدة برمجياً عبر Web Audio — لا ملفات صوتية.
- **الخطوط** من Google Fonts (تحتاج إنترنت أول مرة فقط، ثم تُخزّن).

## ⚠️ حدود نظام الحسابات الحالي

التحقق من كلمة المرور يتم **على جهاز المستخدم** (لا يوجد خادم). عملياً:

- كلمات المرور مجزّأة بـ PBKDF2-SHA256 (٢١٠٬٠٠٠ دورة) + ملح عشوائي — لا تُخزَّن كنص صريح.
- الحسابات محفوظة في `localStorage` الخاص بكل متصفّح، فلا تنتقل بين الأجهزة.
- **من يفتح أدوات المطوّر يستطيع تعديل دوره محلياً.** لذا هذا النظام مناسب لجهاز عائلي أو فصل دراسي، **وليس** لحماية بيانات حسّاسة أو منافسة بجوائز.

### الترقية إلى تحقّق حقيقي (Cloudflare Workers + D1)

الواجهة مبنية بحيث تعمل بلا تغيير بعد نقل ثلاث دوال فقط إلى الخادم:
`hashPass` / `verifyPass` / `loadSession` → نقاط نهاية `/api/login`, `/api/signup`, `/api/me`
مع جلسات موقّعة (HMAC) في كوكي `HttpOnly`، وجدول `users` في D1.
عندها يصبح الدور والصلاحيات محسومَين من الخادم ولا يمكن العبث بهما.
