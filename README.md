# Math Clash — تحدَّ الأرقام 💧

لعبة حساب ذهني عربية أولًا (مع الإنجليزية)، لهوية «مطر المعادلات»: ليل نيلي، قطرات سماوية، ومكافآت ذهبية، ترافقك فيها الشخصية الأصلية **«قطرة»**.
موقع ثابت بالكامل (HTML + CSS + وحدات JavaScript) **بلا خطوة بناء**، يعمل بلا إنترنت بعد أول زيارة، ويُنشر على Cloudflare Pages كما هو.

> الفئة المستهدفة (من محتوى النسخة السابقة): الأطفال واليافعون من ٤ إلى ١٢+ سنة والعائلات والفصول الدراسية — لذلك أُبقيت الكسور والنسب والأقواس والسوالب كموضوعات اختيارية ومتدرّجة.

---

## التشغيل محليًا

```bash
npm install          # لأداة الاختبار فقط (Playwright)
npm start            # يخدم مجلد public على http://localhost:4173
npm test             # اختبارات المنطق (الحساب، النقاط، الحفظ، الترحيل، الأنماط)
npm run test:e2e     # اختبارات الواجهة في Chromium حقيقي
```

> لأن الشيفرة وحدات ES، يجب فتح اللعبة عبر خادم (أي خادم ملفات ثابت)، لا بفتح `index.html` مباشرة من القرص.

## النشر على Cloudflare Pages

- **Framework preset:** None — **Build command:** (فارغ) — **Build output directory:** `public`
- أو: `npx wrangler pages deploy public --project-name=math-clash`
- قبل كل نشر بعد تعديل الملفات: `node scripts/build-sw.mjs` (يحدّث قائمة ملفات عامل الخدمة ورقم الإصدار تلقائيًا من المحتوى، فيصل التحديث للمستخدمين).

## الأنماط

| النمط | الفكرة | الإيقاف/الخلفية |

| **رحلة المستويات** | ١٠ عوالم × ١٠ مراحل. لكل مرحلة هدف واضح: «دقة» (٨–١٠ أسئلة، ★ ٧٠٪ · ★★ ٨٥٪ · ★★★ ٩٥٪)، «سرعة» ⚡ (عدد إجابات صحيحة في وقت محدد؛ النجوم بالوقت المتبقي)، «زعيم» 👑 كل عاشرة (١٢ سؤالًا بثلاث محاولات؛ النجوم = المحاولات المتبقية). | يتوقف المؤقت، يُخفى السؤال، ويُستبدل بمكافئ عند المتابعة |
| **تحدي الوقت** | ٣٠/٦٠/١٢٠ ثانية × سهل/متوسط/صعب. الرقم القياسي = عدد الإجابات الصحيحة (ثم النقاط). الصعوبة ترتفع تدريجيًا داخل الجولة. | كما سبق |
| **البقاء** | ٣ محاولات؛ مؤقت لكل سؤال يبدأ من ١٥/١٢/١٠ ث ويقصر ٠٫٢ ث مع كل إجابة صحيحة (حدّ أدنى ٥ ث). | كما سبق |
| **التدريب الحر** | اختيار العمليات (٨ موضوعات)، المستوى (تلقائي أو ١–١٠ مع شرح سياسة المستوى)، شكل السؤال، المؤقت (اختياري ٢٠ ث)، الطول (١٠/٢٠/مفتوح). عند الخطأ: الإجابة الصحيحة + شرح قصير وزر «التالي». | بلا مؤقت: يبقى السؤال؛ بمؤقت: يُستبدل |
| **دروس المنهج** | ٤ مراحل عمرية، ١٠ مسارات، ٥٦ درسًا. ★ ٦٥٪ (يفتح التالي) · ★★ ٨٠٪ · ★★★ ٩٥٪. | يبقى السؤال |
| **التحدي اليومي** | ١٥ سؤالًا ثابتة لكل يوم (البذرة = التاريخ). محاولة رسمية واحدة، ثم أي إعادة «تدريب» بلا مكافأة يومية ولا تغيّر النتيجة الرسمية. سلسلة أيام متتالية. | **لا إيقاف**. الخروج من التطبيق يتخطّى السؤال المعروض (فلا فائدة من الخروج للتفكير)، والخروج اليدوي يعتمد النتيجة الحالية |
| **تحدي صديق** | على الجهاز نفسه: **بالتناوب** (تمرير الجهاز) أو **وجهًا لوجه** (شاشة مقسومة). لكل خانة نفس العملية والمستوى والشكل لكلا اللاعبين بأرقام مختلفة — متكافئة دون أن يستفيد الثاني من مشاهدة الأول. الفائز بالنقاط ثم الصحيح ثم الأسرع. | استبدال بسؤال مكافئ من القالب نفسه |
| **مطر المعادلات** | النمط الكلاسيكي من النسخة الأصلية مبنيًا على المحرّك الجديد: قطرات تسقط وتنفجر عند كتابة ناتجها. | إيقاف مع إخفاء القطرات |

## سياسة الأسئلة

- **كل الإجابات أعداد صحيحة** — لا كسور عشرية، فلا حاجة لأي تقريب.
- **القسمة** دائمًا بلا باقٍ، والمقسوم عليه ≥ ٢ (لا قسمة على صفر).
- **الضرب** لا يستخدم الصفر عاملًا (فالعدد المفقود له حل وحيد).
- **السوالب**: ناتج الطرح قد يكون سالبًا من المستوى ٨، ومعامل سالب في الجمع من المستوى ٩، أو في مسار «الأعداد السالبة». تُكتب بين قوسين داخل المعادلة: `5 + (−3)`.
- **الكسور**: «كسر من عدد» بمقام يقسم العدد دائمًا. **النسب**: نسب شائعة بناتج صحيح.
- **الصيغ**: إدخال الناتج، اختيار من ٤ (خيارات متمايزة ومعقولة ولا سالب إلا إن سمحت السياسة)، العدد المفقود، والمقارنة بين تعبيرين (اضغط الأكبر أو «=»؛ لا يُقارن تعبير بنفسه).
- **منع التكرار**: ذاكرة لآخر ١٤ سؤالًا، ومعاملة `3+5` و`5+3` كسؤال واحد.
- **الاتجاه**: كل معادلة معزولة الاتجاه (LTR) داخل الواجهة العربية فلا تنعكس `5 − 3` إلى `3 − 5`. جمل مثل «⅓ من ٩» تتبع اتجاه الواجهة.
- **الإدخال**: يقبل الأرقام العربية (٠–٩) والفارسية والإنجليزية من لوحة المفاتيح، ولوحة أرقام على الشاشة.

### الصعوبة التكيّفية
لكل عملية تقدير مهارة من ١ إلى ١٠. لا يتغيّر إلا بعد **٦ إجابات جديدة على الأقل** في العملية نفسها، ويُحكم على **آخر ٨ إجابات**: الدقة ووسيط زمن الإجابة نسبةً للزمن المتوقّع للمستوى. الخطوة ±٠٫٢٥ أو ±٠٫٥ فقط — فلا قفزات، وخطأ واحد لا يخفض المستوى. يستخدمه «التدريب الحر» بالمستوى التلقائي.

## النقاط والتقدّم

- إجابة صحيحة: **١٠٠ + ١٠ لكل مستوى** فوق الأول.
- **السلسلة**: +١٠٪ لكل إجابة صحيحة متتالية حتى ×١٫٥.
- **السرعة** (الأنماط الموقوتة فقط): حتى +٥٠ ضمن الزمن المتوقع، تتناقص حتى صفر عند ضعفه.
- الخطأ = صفر ويصفّر السلسلة. **لا نقاط سالبة**.
- **مكافأة الدقة** (مراحل الدقة واليومي): حتى +٢٠٠ عند ١٠٠٪ (تبدأ من ٧٠٪).
- **الخبرة والمستويات**: ١٠ خبرة لكل إجابة صحيحة + مكافآت النجوم والمهام؛ المستوى n يحتاج ‎100 + 40(n−1)‎ خبرة.
- **١٨ شارة** لإنجازات حقيقية، **٣ مهام يومية** (إحداها التحدي اليومي)، و**مظاهر تجميلية** (٦ سمات، ٦ ألوان لـ«قطرة»، ٦ إكسسوارات) تُفتح بالمستوى أو الشارات ولا تؤثر على الصعوبة أو النقاط.
- **تطبيق المكافآت مرة واحدة**: كل جولة لها معرّف، و`commitRound` يرفض تطبيقها مرتين (حتى بعد تحديث الصفحة أو الاستئناف).

## صفحة «تقدّمي» — تعريف المؤشرات

- **السؤال المُجاب**: كل سؤال أجيب عنه أو انتهى وقته. المتخطّى (خروج من اليومي) لا يُحتسب.
- **الدقة** = الصحيحة ÷ المجابة.
- **متوسط زمن الإجابة** = من ظهور السؤال حتى الإجابة، دون فترات الإيقاف ودون الأسئلة المنتهي وقتها ونمط المطر.
- **الجولة**: تُحتسب عند اكتمالها (أو إنهاء التدريب). المتروكة لا تُحتسب جولة لكن إجاباتها الحقيقية تُحتسب.
- **مستوى العملية**: تقدير المهارة التكيّفي أعلاه.
- **التطوّر**: أعمدة لعدد الأسئلة وخط للدقة لآخر ١٤ يومًا.
- **التوصية**: العملية الأقل دقة (بعيّنة ≥ ١٠)، أو الأبطأ، أو اقتراح رفع المستوى — وتحتاج ٢٠ سؤالًا على الأقل.
- لا أسماء ولا ترتيب عالمي وهمي: كل الأرقام من لعب هذا الجهاز.

## الحفظ والاستئناف (حدود واضحة)

- كل شيء محفوظ في **localStorage لهذا المتصفح على هذا الجهاز فقط**. **لا توجد مزامنة سحابية ولا خادم.** مسح بيانات المتصفح يحذف التقدّم؛ يتوفر **تصدير/استيراد** نسخة JSON من الإعدادات.
- إن منع المتصفح الحفظ (التصفح الخاص مثلًا) تعمل اللعبة من الذاكرة وتعرض تنبيهًا.
- **الجولة الجارية** تُحفظ بعد كل إجابة وعند الإيقاف؛ بعد تحديث الصفحة أو إغلاقها تعرض الرئيسية «استئناف» أو «إنهاء دون نتيجة» (اليومي الرسمي: «إنهاء» يعتمد النتيجة الحالية). تحدي صديق ومطر المعادلات لا يُستأنفان بعد إعادة التحميل.
- **الملفات الشخصية**: عدة لاعبين على الجهاز نفسه، بيانات كل منهم منفصلة (مفاتيح مستقلة). كلمة مرور اختيارية (PBKDF2-SHA256 بنفس صيغة النسخة السابقة) تمنع اللعب بملف غيرك على الجهاز نفسه فقط — **وليست حماية أمنية**، فمن يفتح أدوات المطوّر يصل إلى البيانات.

### الترحيل من النسخة السابقة
عند أول تشغيل تُنقل حسابات النسخة السابقة (`mc_users` و`mc_prog:*` و`mc_set:*` و`mc_stats:*`) إلى ملفات شخصية: المرحلة المفتوحة ونجوم المراحل ونجوم الدروس وإعدادات اللغة والأرقام والصوت والاهتزاز وسلسلة التحدي اليومي وأطول سلسلة، وتُمنح خبرة مقابل التقدّم السابق. **المفاتيح القديمة لا تُحذف**. ملفات التصدير القديمة (v1) يمكن استيرادها أيضًا.

## ما الذي تغيّر عن النسخة السابقة ولماذا

- **أُزيلت أنماط «الأونلاين» والغرف والبطولة ولوحة الصدارة**: كانت محاكاة محلية بأسماء ونتائج وهمية (الخصوم بوتات). اللعب الحقيقي بين أجهزة يتطلب خادمًا (مثل Cloudflare Workers + Durable Objects) غير متوفر حاليًا، لذلك لم تُعرض كميزات جاهزة.
- **أُزيلت لوحة المدير والأدوار** (مدير/معلّم/لاعب) لأن وظيفتها كانت التحكم في تلك الأنماط؛ أصبح إنشاء الحساب اختياريًا ويبدأ اللعب فورًا.
- **الشاشة المقسومة للاعبين** بقيت كخيار «وجهًا لوجه» داخل تحدي صديق، و**الطور التعليمي** بقي كـ«دروس المنهج»، و**مطر المعادلات** بقي كنمط كلاسيكي.
- **اللغات**: العربية والإنجليزية كاملتان. لغات النسخة السابقة الإحدى عشرة باقية في قائمة اللغات مع ترجمة العناوين الأساسية فقط، وأي نص غير مترجم يظهر بالإنجليزية (في النسخة السابقة كان معظم النص عربيًا ثابتًا في كل اللغات).
- الخطوط أصبحت مستضافة محليًا (لا اتصال بخدمات خارجية)، ولا توجد أي خدمة مدفوعة.

## الاختبارات

- `npm test` — منطق الأسئلة (صحة كل الإجابات لكل عملية ومستوى وصيغة، القسمة، السوالب، الخيارات، التكرار)، المحرّك (النقر المزدوج، الإجابة في اللحظة الأخيرة، انتهاء الوقت، الإيقاف والاستبدال، التخطّي، اللقطة والاستئناف)، النقاط، التكيّف، المكافآت مرة واحدة، المهام، الشارات، اليومي، الحفظ والترحيل وفصل الملفات، المطر، واكتمال الترجمات.
- `npm run test:e2e` — رحلة اللاعب كاملة في Chromium: الشرح والتخطّي، اجتياز المرحلة بثلاث نجوم، الخسارة وإعادة اللعب، النقر المزدوج، الأرقام العربية، شرح الخطأ، الخروج دون مكافأة، التحديث أثناء الجولة والاستئناف دون تكرار، الإيقاف والخلفية، انتهاء تحدي الوقت، اليومي (رسمي مرة واحدة)، البقاء، كل الشاشات بلا أخطاء وبلا تمرير أفقي على ٣٢٠ بكسل، التنقل واللغة، صفحة التقدّم، تحدي الصديق بالنمطين، المطر، فصل الملفات وكلمة المرور، ترحيل البيانات القديمة، واللعب بلوحة المفاتيح فقط.
